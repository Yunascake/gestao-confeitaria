# Gestão Confeitaria

Sistema de gestão de confeitaria que usa uma planilha Excel (`.xlsx`) como arquivo de dados.

## Como usar

1. Abra o site.
2. Carregue a planilha existente ou crie uma nova.
3. Faça os cadastros e alterações no sistema.
4. Salve a planilha atualizada no computador.
5. Na próxima utilização, carregue novamente essa planilha.

Os dados da planilha são processados no navegador e não são armazenados neste repositório.
